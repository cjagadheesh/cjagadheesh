## Projects

**[IPO Sherpa](https://github.com/cjagadheesh/Automated-IPO-Drafter)**, 2nd prize at SEBI TechSprint 2026 (Global Fintech Fest)
A FastAPI and React platform that checks SME IPO documents against SEBI ICDR rules and drafts parts of the prospectus. It ships as Docker containers and has a 75-test suite that runs offline, without calling external APIs.
`Docker` `FastAPI` `React` `OCR` `RAG`

**[OceanPulse](https://github.com/cjagadheesh/Freight-Cost-Detection-using-garch-and-catboost)**
Freight cost forecasting (GARCH, CatBoost) with a FastAPI backend, React frontend and a PuLP procurement planner. The bundled dataset is illustrative.
`FastAPI` `React` `Python`

**[College multilingual chatbot](https://github.com/cjagadheesh/Multilingual-Chatbot)**
A Flask service answering college questions in English, Hindi and Tamil, by text or voice, using ChromaDB retrieval, Gemini and Azure Speech.
`Flask` `ChromaDB` `Azure`
